# Pattern Catalogue

The **Pattern Catalogue** is an item that is used to store [[Signs|Traffic Sign]] Patterns and apply them to Traffic Signs.  
A creative variant exists which has all default pattern available by default.

## Usage

Putting the Pattern Catalogue in a [[Traffic Sign Workbench]] allows you to add new Traffic Sign Patterns to it.  
Currently stored Patterns are visible in the Item's lore when hovering over it and the currently selected pattern can be applied to Traffic Signs, by right-clicking them with the Pattern Catalogue.

Right-clicking the air with it will open a GUI displaying all currently stored Traffic Sign Patterns, allowing you to select the one to use on Traffic Signs.
