# Paint Brush

The **Paint Brush** is an item that can be used to paint patterns on [[Asphalt]] and [[Concrete]] Blocks and Slopes or apply color to other specific TrafficCraft blocks.

## Usage

Right-clicking the air with a Paint Brush opens a GUI, allowing you to select a Road Pattern. This pattern can be applied to any Asphalt and Concrete (Slope).  
To apply the pattern to an Asphalt or Concrete (Slope), or to paint other supported Blocks, first you need to apply paint to the Paint Brush by right-clicking it on a [[Paint Bucket]] filled with any [[mc:dye]]. If the Paint Brush already has color applied, will it be overriden.

A full Paint Brush allows 128 Blocks to be painted.

Right-clicking Asphalt or Concrete (Slopes) will apply the selected pattern. Repeated right-clicking will rotate the pattern by 90° clock-wise.  
Other supported TrafficCraft blocks will change parts of their texture to the applied color. See the [`TrafficCraft/Paintable`](../../categories/trafficcraft-paintable.md) category for all paintable Blocks.
