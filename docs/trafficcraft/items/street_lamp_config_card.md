# Street Lamp Configuration Card

The **Street Lamp Configuration Card** is an item that can be used to configure street lamps turning on and off at specific times of the day.

## Functionality

Right-clicking the air with the tool opens a GUI that allows you to configure the on and off-time.

### Time Format

Pressing this button switches the displayed time format between *24 Hours* (Default), *12 Hours* and *Ticks*.

### Turn on at

Sets the time at which the light should turn on.  
The slider can range from 00:00[^1] up to 23:45[^2].

The default time is 00:30[^3].

### Turn off at

Sets the time at which the light should turn off.  
The slider can range from 00:00[^1] up to 23:45[^2].

The default time is 11:30[^4].
