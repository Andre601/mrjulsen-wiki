# Hammer

The **Hammer** is a tool that is used in crafting recipes, but can also be used on [[Asphalt Slope|Asphalt Slopes]] and [[Concrete Slope|Concrete Slopes]].

## Usage

The Hammer can be used in the crafting field alongside an iron ingot to craft [[Iron Plate|Iron Plates]].

While holding it, breaking Asphalt or Concrete slopes will only remove one layer instead of breaking the entire block. This will use up 1 durability from the tool.  
Up to 250 blocks can be broken with one Hammer.
