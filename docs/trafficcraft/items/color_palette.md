# Color Palette

The **Color Palette** is an Item that can be used in the Traffic Sign Workbench to store and load colors.  
It allows to store up to 7 colors at once.

## Usage

Placing the Color Palette in the designated slot in the Traffic Sign Workbench will add 7 slots to the right side of the GUI.  
Left-clicking a slot will select the stored color while right-clicking will store the currently set color from the Workbench. Middle-clicking the slot will reset it.
