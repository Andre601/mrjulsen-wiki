# Asphalt Slope

/// redirect | `Asphalt with Curb Slope` redirects here.
///

**Asphalt Slope** is a Block that can be painted with the [[Paint Brush]] and stacked similar to [[mc:Snow]].

## Usage

Right-clicking with an Asphalt Slope on an existing Asphalt Slope will add a layer to it, increasing its size by 2 pixels.

Using a Paint Brush, a configured pattern can be painted on the Asphalt Slope Block.  
If the Asphalt Block has the same pattern already, will any right-click with the Paint Brush rotate it clockwise.
