# Bitumen Ore

**Bitumen Ore** is a Block that spawns naturally in the World. It exists in a normal and deepslate variant.

## Generation

Bitumen Ore spawns naturally in clusters of up to 25 blocks between Y levels 55 and 75 inclusive.  
Up to two clusters can be generated per chunk and replace any block containing the [[mc:Tag (Java_Edition)|`#minecraft:stone_ore_replaceables` or `#minecraft:deepslate_ore_replaceables`]] with the second one placing the Deepslate variant.

## Obtaining

### Mining

Bitument Ore can be mined with a Pickaxe of Stone Tier or better, dropping [[Raw Bitumen]].  
Using a Pickaxe with Silk Touch Enchantment drops the Block itself.
