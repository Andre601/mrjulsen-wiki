# Traffic Sign

The **Traffic Sign** is a Block that can display custom Patterns applied to it through a [[Pattern Catalogue]].

## Usage

Right-clicking the Traffic Sign with a Pattern Catalogue containing at least one Pattern will transfer the selected pattern to the Block itself, displaying it.
