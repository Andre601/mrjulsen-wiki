# Traffic Blocks

/// redirect | `Traffic Cone`, `Traffic Bollard`, `Traffic Barrel` and `Raod Barrier Fence` redirect to here.
///

This page is a collection of the **Traffic Cone**, **Traffic Bollard**, **Traffic Barrel** and **Road Barrier Fence** which all provide the same functionality, being a decorative block having a 1.5 block high collission block similar to a [[mc:Fence]].

## Usage

Placing any Traffic Block down will be similar to placing a Fence Block, with its collission box being 1.5 blocks while the displayed model is only 1 block in height.  
The blocks may also be placed into the Helmet Armor slot, displaying them on top of the player's head with the Traffic Cone having a slight tilt added, and the Road Barrier Fence being inside the player's head.
