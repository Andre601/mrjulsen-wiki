# Paint Bucket

The **Paint Bucket** is a Block that can be filled with [[mc:Dye|Dyes]] to then apply to a [[Paint Brush]] to paint markings on [[Asphalt]] and [[Concrete]] blocks with.

## Usage

Right-clicking a Paint Bucket with any Dye item will fill it by one level. Up to 8 dyes of the same color can be added, allowing to paint 8 * 128 (1,024) blocks with a full Bucket.  
Trying to add a dye while the Bucket is already filled with one of a different color will do nothing.

Right-clicking the Bucket with a Paint Brush will remove 1 level from the Paint Bucket while applying the dye to the Paint Brush. This will also update the Paint Brush's color, if it is different and refresh its usage count to 128 uses.

Breaking the Bucket will discard any paint it may had.
