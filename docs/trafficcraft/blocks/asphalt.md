# Asphalt

/// redirect | `Asphalt with Curb` redirects here.
///

**Asphalt** is a Block that can be painted with the [Paint Brush](../items/paint_brush.md).

## Usage

Using a Paint Brush, a configured pattern can be painted on the Asphalt Block.  
If the Asphalt Block has the same pattern already, will any right-click with the Paint Brush rotate it clockwise.

Asphalt with Curb cannot be painted
