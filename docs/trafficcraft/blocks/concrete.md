# Concrete

/// redirect | `Concrete with Curb` redirects here.
///

**Concrete** is a Block that can be painted with the [[Paint Brush]]

## Usage

Using a Paint Brush, a configured pattern can be painted on the Concrete Block.  
If the Concrete Block has the same pattern already, will any right-click with the Paint Brush rotate it clockwise.

/// note
Concrete with Curb cannot be painted
///
