# Traffic Light Request Button

The **Traffic Light Request Button** is a Block that can be linked to a [Traffic Light](traffic_light.md) or a [Traffic Light Controller](traffic_light_controller.md) and allows to trigger a schedule to be executed, if configured.

## Usage

Right-clicking the Block's front face results in the button getting pressed. The button remains pressed for 10 seconds, similar to a [[mc:Stone_Button|Stone Button]].

Connecting the Button to a Traffic Light or Traffic Light Controller allows to remotely trigger its schedule, if the Light or Controller is configured to *On Request*.
