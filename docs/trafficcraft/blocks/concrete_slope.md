# Concrete Slope

/// redirect | `Concrete with Curb Slope` redirects here.
///

**Concrete Slope** is a Block that can be painted with the [Paint Brush](../items/paint_brush.md) and stacked similar to [[mc:Snow|Snow]].

## Usage

Right-clicking with an Concrete Slope on an existing Concrete Slope will add a layer to it, increasing its size by 2 pixels.

Using a Paint Brush, a configured pattern can be painted on the Concrete Slope Block.  
If the Concrete Block has the same pattern already, will any right-click with the Paint Brush rotate it clockwise.
