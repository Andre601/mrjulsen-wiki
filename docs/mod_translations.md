# Mod Translations

Since I don't speak all languages ​​and I want my mods to be available in different languages, community support for localizing is greatly appreciated!
All my mod translations are hosted on Crowdin.

[![](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3.3.1/assets/cozy/translate/crowdin_vector.svg)](https://crowdin.com/profile/mrjulsen)

## Requirements

Anyone can translate the mods into their language of choice. You can expand and correct existing translations or request new languages.
For this, the following requirements apply:

- You have good skills in the language you want to translate into to create high-quality translations.
- You understand English well enough to translate the original texts accurately and meaningfully.
- You understand how texts are structured in Minecraft (placeholders, formatting, etc.).

To become a translator, you need to create a Crowdin account. This alone is enough to create translations. You can also join the project by clicking the green "Join" button on the dashboard. This way, you'll always be informed about changes and will also appear in the list of contributors.

## Verification

Since I cannot check who produces good and "bad" translations, there is usually no official review of the written texts.
The translations are entirely done and reviewed by the community. The translations are then used in their current version before each mod update.
Always keep that in mind when using the translations in my mods!

- Please correct any errors in the translations or talk to other translators.
- If you are unsure, ask other translators or leave the text open.
- Pay attention to good spelling and grammar.
- Do not abuse this offer to help with localization and report any abuse.

## Language support

If you want to translate a language that isn't available, contact me either on Discord or in the Crowdin discussions. I'll add the missing language as soon as possible and if it makes sense.
