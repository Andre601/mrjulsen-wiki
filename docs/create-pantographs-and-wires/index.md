# Create: Pantographs & Wires

**Create: Pantographs & Wires** or P&W for short, is a Create Mod addon that adds new features for electrical trains, like catenary wires, Pantographs and more.

## Dependencies

- The Mod requires [Create](https://modrinth.com/mod/create) or [its Fabric Port](https://modrinth.com/mod/create-fabric).
    - Versions with `C6` are compatible with Create 6 while versions without this suffix are compatible with Create 5 (Unless Create 6 is the only version available for that Minecraft Version).
- Versions `0.2.0` and newer require [DragonLib](https://modrinth.com/mod/dragonlib){ target="_blank" rel="nofollow" } to be installed. Versions `0.1.2` and older do not require it.
