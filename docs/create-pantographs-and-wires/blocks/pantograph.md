# Pantograph

The pantograph is placed on the roof of trains and is used to draw electrical power from the catenary wire above it that powers the train.

## Usage and Behaviour

The pantograph can be **expanded or collapsed** by right‑clicking it. When extended, pantographs automatically adjust their height to match the catenary wire above them. This only works if the pantograph is placed on an **assembled train**. Otherwise, it will extend to its **default height of 3 blocks**, ignoring any catenary wires.

If no catenary wire is present above the pantograph, it will automatically fold back down. As soon as a wire is detected above it again, the pantograph will extend automatically.
