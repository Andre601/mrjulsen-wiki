# Navigation warning

If a warning is displayed in the Navigator that some routes cannot be suggested correctly, this means that CRN has not yet initialized all trains.
This warning does not describe a serious problem, but serves an explanatory function. Because CRN has not initialized all trains, CRN cannot use all trains to calculate routes. This can then lead to less efficient routes or, in the worst case, the destination cannot be reached and an incomplete or completely missing route is returned.
If this warning does not disappear even after a longer playtime, it can be helpful to check the trains to see whether all trains are actually running correctly. The blacklist can also help to exclude trains that should not be taken into account.
