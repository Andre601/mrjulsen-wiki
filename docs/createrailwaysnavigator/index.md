# Create Railways Navigator

**Create Railways Navigator** or CRN for short, is a Create Mod addon that adds new features related to train navigation, such as improved display boards, a navigator for searching routes, new schedule entries, and more.

## Dependencies

- The Mod requires [Create](https://modrinth.com/mod/create) or [its Fabric Port](https://modrinth.com/mod/create-fabric).
    - Versions with `C6` are compatible with Create 6 while versions without this suffix are compatible with Create 5 (Unless Create 6 is the only version available for that Minecraft Version).
- Versions `0.9.0` and newer require [DragonLib](https://modrinth.com/mod/dragonlib){ target="_blank" rel="nofollow" } to be installed. Versions `0.8.5` and older do not require it.

-   ### [[Navigator]]
    Use the Navigator which is inspired by the [DB Navigator App](https://de.wikipedia.org/wiki/DB_Navigator){ target="_blank" rel="nofollow" } to find routes between two stations on your rail network.  
    You will also be able to see departure times, delays and other details.

    An improved version of the [[c:Display Board]] from create, specifically designed for trains and stations.  
    Display next stops or trains arriving on/departing from a Station.
-   ### New Schedule Features
    Define new features in schedules such as [[Dynamic Delay|dynamic delays]], [[Prioritized Destination Instruction|prioritized destinations]] and more.
-   ### Additional Features
    New features to [[Blacklists|blacklist trains and stations]], [[Train Lines|define train lines]] and more.
