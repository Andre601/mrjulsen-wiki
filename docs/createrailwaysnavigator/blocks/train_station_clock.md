# Train Station Clock

The **Train Station Clock** is a decorative block that displays the current ingame time.

## Usage

Right-clicking the Click with another Train Station Clock will change its display from a 2-sided Clock to a 4-sided one.  
Clicking it with any other item, or an empty hand, displays the current ingame time as an Actionbar text.
